## 🌟 Key Features

- 🛫 **Travel Logging & Memories:**
  - Create travel entries with destination names, personal ratings (0–5 stars), detailed notes, and gallery photos.

- 🔍 **Real-Time Destination Search:**
  - Instant live search that filters travel spots as you type.

- ⭐ **Top-Rated Recommendations:**
  - Automatically highlights the most loved places based on average community ratings.

- 📚 **Personal Travel Diary:**
  - Dedicated space on the dashboard where users can quickly review all their own past journeys.

- 🔐 **User Accounts & Custom Profiles:**
  - Fast registration and login system with custom profile picture upload and account editing.

- 📴 **Offline-First & Fast:**
  - Powered by local SQLite storage—access and log your trips anytime, anywhere without an active internet connection.

---

## 🛠️ Tech Stack

- **Language:** Kotlin
- **Platform:** Android (Min SDK 24, Target SDK 35)
- **Architecture:** Single Activity Architecture with Modular Fragments
- **UI & Layouts:** XML, Material Design Components, ConstraintLayout, Dynamic RecyclerViews
- **Local Storage:** SQLite Relational Database, Internal Storage Image Caching
- **Media & Permissions:** Modern Android Photo Picker & Runtime Permissions (Android 13+ compatible)
